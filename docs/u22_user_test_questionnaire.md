# U-22 ユーザーテスト質問票

## 使い方

中学生が VCL を触った後、短い時間で聞くための質問票。口頭で聞いて、進行担当がメモしてもよい。

## 基本質問

| 質問 | メモ |
| --- | --- |
| どこが一番分かりやすかったですか。 |  |
| どこで迷いましたか。 |  |
| Joy-Con を使う操作は実験っぽく感じましたか。 |  |
| 画面の文字や説明で難しいところはありましたか。 |  |
| もう一度やるなら、どの実験をやってみたいですか。 |  |

## 操作について

| 質問 | メモ |
| --- | --- |
| Joy-Con を傾ける操作は分かりやすかったですか。 |  |
| Joy-Con を振って混ぜる操作は分かりやすかったですか。 |  |
| 次に何をすればよいか、画面を見て分かりましたか。 |  |
| 実験が成功したことは分かりましたか。 |  |

## 学習について

| 質問 | メモ |
| --- | --- |
| 実験で何が起きたか分かりましたか。 |  |
| 実験後の説明は読みやすかったですか。 |  |
| 実際の理科の授業でも使ってみたいと思いましたか。 |  |
