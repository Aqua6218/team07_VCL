# Joy-Con 接続マニュアル

## 目的

U-22 プログラミング・コンテスト用の動画撮影と中学生向けユーザーテストで、現地担当者が Joy-Con と PC の接続を説明できるようにする。

この資料は、アプリの細かい操作説明ではなく、Joy-Con を PC に接続して VCL の接続ガイドで動作確認するところまでを対象にする。

## 役割

| 担当 | 役割 |
| --- | --- |
| 進行担当 | 接続方法の説明、動作確認、ユーザーテストの進行 |
| 撮影担当 | 手元、PC画面、実験中の反応を撮影 |
| 中学生 | Joy-Con を使って VCL を操作 |

## 事前準備

開始前に以下を確認する。

- PC の Bluetooth が使える。
- Joy-Con が充電されている。
- Joy-Con が Switch 本体や別の PC に接続されたままになっていない。
- VCL のバックエンドとフロントエンドを起動している。
- ブラウザで VCL を開き、接続ガイド画面へ移動できる。
- 画面録画と手元撮影の準備ができている。

起動コマンド例:

```powershell
npm run dev
```

## 最初に伝えること

進行担当は、接続前に次のように説明する。

```text
今日は、Joy-Conを使って化学実験をするアプリを触ってもらいます。
最初にJoy-ConとPCのつなぎ方だけ説明します。
その後は、画面を見ながら自分で進めてみてください。
分からないところや迷ったところがあれば、その場で教えてください。
これはみんなをテストするのではなく、アプリが分かりやすいかを見るテストです。
```

## 接続手順

### 1. PC の Bluetooth 設定を開く

Windows の場合:

1. スタートメニューを開く。
2. `設定` を開く。
3. `Bluetooth とデバイス` を開く。
4. Bluetooth が `オン` になっていることを確認する。
5. `デバイスの追加` を押す。
6. `Bluetooth` を選ぶ。

### 2. Joy-Con をペアリングモードにする

1. Joy-Con の側面にある小さいシンクロボタンを長押しする。
2. Joy-Con のランプが流れるように点滅したら、ペアリング待機状態。

説明例:

```text
この小さいボタンを長押しすると、Joy-ConがPCとつながる準備をします。
ランプが動き始めたら、PC側で選べるようになります。
```

### 3. PC 側で Joy-Con を選ぶ

1. PC の Bluetooth 追加画面に `Joy-Con (L)` または `Joy-Con (R)` が出るのを待つ。
2. 表示された Joy-Con を選択する。
3. `接続済み` または `ペアリング済み` になったことを確認する。
4. 2本使う場合は、もう片方の Joy-Con も同じ手順で接続する。

説明例:

```text
PCにJoy-Conが表示されたら、それを選んで接続します。
2本使う場合は、片方ずつ同じようにつなぎます。
```

### 4. VCL の接続ガイドで確認する

1. VCL の接続ガイド画面を開く。
2. Joy-Con を軽く傾ける。
3. 画面上の Joy-Con 表示や角度表示が動くか確認する。
4. `接続完了` 表示になったら、実験に進む。

説明例:

```text
ここでJoy-Conを傾けて、画面の表示が動くか確認します。
画面が動けば、アプリがJoy-Conの動きを受け取れています。
```

## 接続できた後に伝えること

```text
ここから先は、画面を見ながら自分で実験を進めてみてください。
Joy-Conを傾けると注ぐ操作、振ると混ぜる操作になります。
迷ったところがあれば、どこで迷ったかを教えてください。
```

細かいボタン位置や成功条件は、最初から説明しすぎない。中学生が自分で画面を見て進められるかを確認する。

## うまく接続できないとき

### PC に Joy-Con が表示されない

- Joy-Con のシンクロボタンをもう一度長押しする。
- Joy-Con の充電を確認する。
- Bluetooth を一度オフにして、もう一度オンにする。
- Joy-Con が Switch 本体や別の PC に接続されていないか確認する。

### PC では接続済みなのに VCL で動かない

- VCL のバックエンドが起動しているか確認する。
- ブラウザを更新する。
- 接続ガイド画面を開き直す。
- Joy-Con を一度 Bluetooth から削除し、再接続する。
- Joy-Con を接続した直後は数秒置き、キャリブレーションを待つ。

### 片方だけ動く

- もう片方の Joy-Con も PC の Bluetooth 設定で接続済みになっているか確認する。
- 片方ずつ接続し直す。
- VCL を開き直す。

## 撮影時の注意

顔、名札、学校名、個人名が映らないようにする。手元と画面を中心に撮影する。

必ず撮るもの:

- 進行担当が Joy-Con 接続を説明している場面。
- Joy-Con のシンクロボタンを押す手元。
- PC の Bluetooth 画面で Joy-Con を選ぶところ。
- VCL の接続ガイドで、Joy-Con を傾けると画面が動くところ。
- 接続後、中学生が自分で実験を進めるところ。
