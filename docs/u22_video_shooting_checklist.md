# U-22 動画撮影チェックリスト

## 撮影の目的

U-22 プログラミング・コンテスト用動画で、VCL の価値が短時間で伝わる素材を集める。

特に、以下の3点が伝わる映像を優先する。

- Joy-Con を実験器具のように使えること。
- 中学生が実際に操作できること。
- 化学反応を安全に体験できること。

## 必ず撮る場面

| 優先度 | 場面 | 撮影内容 |
| --- | --- | --- |
| 高 | 接続ガイド | Joy-Con を傾けると画面の Joy-Con 表示が動く |
| 高 | 実験操作 | Joy-Con を傾けて薬品を注ぐ |
| 高 | 混合操作 | Joy-Con を振って混ぜる |
| 高 | 反応演出 | 色変化、泡、沈殿などが出る瞬間 |
| 高 | 中学生の操作 | 手元と画面を同時に撮る |
| 中 | 実験選択 | 中学生が実験を選ぶところ |
| 中 | 解説表示 | 実験後の結果や解説が表示されるところ |
| 中 | トロフィー | 成功後に達成感が分かる画面 |

## 撮らないもの

- 顔がはっきり分かる映像。
- 名札、学校名、個人名。
- 周囲の生徒の顔や会話。
- パスワード、メールアドレス、個人情報が映る画面。

## 撮影のコツ

- 画面だけでなく、Joy-Conを持つ手元も入れる。
- 反応が出る瞬間は、画面を止めずに数秒長めに撮る。
- 接続でうまくいった瞬間も撮る。
- 音声は無理にきれいにしなくてよいが、説明の声が入る場面は静かにする。
- 縦動画ではなく、できれば横向きで撮る。

## 動画に使いやすい一言

現地で言える場合は、短く入れる。

```text
Joy-Conを傾けると、画面の実験器具も一緒に動きます。
```

```text
実際の薬品を使わなくても、化学反応の流れを安全に体験できます。
```

```text
中学生が自分で操作しながら、実験の流れを学べるようにしています。
```

## 最低限ほしい素材

時間がない場合は、この3つだけは必ず撮る。

1. Joy-Con を傾ける手元と、画面が動くところ。
2. 中学生がJoy-Conで実験を進めているところ。
3. 化学反応が出て、結果や解説が表示されるところ。
