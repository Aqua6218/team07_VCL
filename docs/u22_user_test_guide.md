# U-22 動画用ユーザーテスト進行ガイド

## 目的

中学生に VCL を実際に触ってもらい、U-22 プログラミング・コンテスト用動画に使える利用シーンと、改善に必要な気づきを集める。

このテストでは、中学生が正しく操作できるかだけでなく、画面を見て自然に進められるか、Joy-Con を実験器具として直感的に使えるかを確認する。

## 当日のゴール

- Joy-Con 接続から実験開始までの様子を撮影する。
- 中学生が VCL を操作している手元と画面を撮影する。
- 実験の反応が出た瞬間を撮影する。
- 迷った場所、分かりにくかった言葉、楽しかった操作を記録する。

## テスト前の確認

- PC、充電器、Joy-Con、撮影機材を用意する。
- VCL のフロントエンドとバックエンドを起動する。
- 接続ガイド画面を開けることを確認する。
- 実験室画面で少なくとも1つの実験が最後まで動くことを確認する。
- 撮影してよい範囲を確認する。
- 顔、名札、学校名、個人名が映らないようにする。

## 進行の流れ

### 1. 導入

```text
今日は、Joy-Conを使って化学実験を体験できるアプリを触ってもらいます。
これはみんなの知識をテストするものではなく、アプリが分かりやすいかを見るためのテストです。
分からないところや迷ったところがあれば、そのまま教えてください。
```

### 2. Joy-Con 接続

`docs/joycon_connection_manual.md` に沿って、PC と Joy-Con を接続する。

接続の説明は最小限にして、接続後は中学生自身が画面を見て進めるようにする。

### 3. 接続ガイドで動作確認

確認すること:

- Joy-Con を傾けると画面の表示が動く。
- 接続状態が分かる。
- 実験開始へ進める。

記録すること:

- 接続完了が分かったか。
- どの画面を見ればよいか迷わなかったか。
- Joy-Con の動きと画面の動きが結びついて見えたか。

### 4. 実験を進めてもらう

中学生には、なるべく画面を見ながら自分で進めてもらう。

進行担当は、最初から答えを教えすぎない。止まった場合は、どこで迷ったかを聞いてから最小限だけ補助する。

見るポイント:

- 実験を選べるか。
- 薬品を入れる操作が分かるか。
- Joy-Con を傾ける、振る操作が分かるか。
- 反応が出たときに何が起きたか理解できるか。
- 解説画面を読もうとするか。

### 5. 終了後に短く質問する

時間をかけすぎず、3分程度で聞く。

```text
1. どこが一番分かりやすかったですか。
2. どこで迷いましたか。
3. Joy-Conを使う操作は実験っぽく感じましたか。
4. もう一度やるなら、どの実験をやってみたいですか。
5. 画面の文字や説明で難しいところはありましたか。
```

## 失敗しても撮るべき場面

接続や操作で少し詰まった場面も、改善点として価値がある。動画本編に使わない場合でも、開発チームの振り返りに使える。

ただし、本人が困っている様子を強調しすぎない。撮影は手元と画面中心にする。
